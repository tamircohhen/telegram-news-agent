# ABU TAMER NEWS – סוכן חדשות לערוץ Telegram

הסוכן בודק כל 10 דקות מקורות חדשות בישראל ובעולם, מסנן את הידיעות החשובות על המלחמה מול איראן, על ארה"ב ועל נושאים שמשפיעים על ישראל, ומפרסם אותן בערוץ @AbuTamerNews בעברית רשמית עם הסבר מונחים, תמונה וקישור למקור. נושאים ביטחוניים רגישים נשלחים קודם אליך לאישור בלחיצת כפתור. בכל ערב ב-20:00 מתפרסם סיכום יומי.

מקורות RSS ← סינון ודירוג (Claude) ← כתיבה בעברית (Claude) ← הערוץ, או אליך לאישור אם הנושא רגיש

## הגדרת הסודות (Settings ← Secrets and variables ← Actions ← New repository secret)

| שם | ערך |
|---|---|
| TELEGRAM_BOT_TOKEN | הטוקן מ-BotFather |
| TELEGRAM_CHANNEL_ID | @AbuTamerNews |
| ANTHROPIC_API_KEY | המפתח מ-platform.claude.com |
| ADMIN_CHAT_ID | המספר שלך (מתקבל מבדיקת ההתקנה) |

## בדיקה והפעלה
1. לשונית Actions ← check-setup ← Run workflow. הפלט מציג את מצב הבוט, הערוץ, מפתח Claude והמקורות, וגם את ה-ADMIN_CHAT_ID שלך.
2. Actions ← news-agent ← Run workflow להרצה ראשונה. מכאן הסוכן רץ לבד כל 10 דקות.

## מצב ניסיון חסכוני (פעיל כרגע)
- שני המודלים הם Claude Haiku, הזול ביותר.
- רק ידיעות בחשיבות 3 ומעלה, עד 3 פוסטים בהרצה ועד 25 פוסטים ביממה (תקרה קשיחה).
- למעבר למצב מלא ערוך את config.yaml: min_importance: 2, max_posts_per_run: 6, daily_post_cap: 80, writer_model: claude-sonnet-5-5. למהירות מרבית שנה בקובץ .github/workflows/news.yml את התזמון ל-"*/5 * * * *".

## שימוש יומיומי
- אישור פוסט: כשמגיע אליך פוסט "ממתין לאישורך", לחץ ✅ פרסם או ❌ דחה. ההחלטה נקלטת בהרצה הבאה. פריט שלא טופל 12 שעות פג.
- השהיה: Actions ← news-agent ← ⋯ ← Disable workflow.
- שינוי הגדרות: עריכת config.yaml ישירות ב-GitHub (סמל העיפרון). אפשר לשנות מצב פרסום (auto / hybrid / approval), סף חשיבות, תקרות ומקורות.

## מה נחשב "רגיש" ונשלח לאישור
מיקומי נפילות ויירוטים, תנועות כוחות, שמות נפגעים לפני הותרתם לפרסום, פרטים על חטופים, מודיעין שדלף, ודיווחים על תקיפה ישראלית לפני אישור רשמי.

⚠️ צנזורה צבאית: ערוץ ישראלי שמפרסם ידיעות ביטחוניות כפוף להנחיות הצנזורה. הסוכן משמיט פרטים כאלה ומעביר אותם לאישורך, אבל האחריות הסופית לפרסום היא של בעל הערוץ. באירוע ביטחוני חריג כדאי לעבור זמנית ל-publish_mode: approval.

## תמונות
הסוכן לא מוריד תמונות מאתרי חדשות (זכויות יוצרים). Telegram מציג מעל כל פוסט תצוגה מקדימה גדולה של הכתבה, עם התמונה הראשית שלה וקרדיט למקור.

## עלויות
- GitHub Actions במאגר ציבורי ו-Telegram: ללא עלות.
- Claude API: במצב ניסיון כמה סנטים ביום. Auto-reload כבוי, כך שאין חיוב מעבר לקרדיט שנטען.
